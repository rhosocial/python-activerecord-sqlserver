# rhosocial-activerecord-sqlserver Documentation

This is the documentation for the SQL Server backend of
[rhosocial-activerecord](https://github.com/rhosocial/python-activerecord). It
covers only what is specific to SQL Server — connection and configuration, the
native types and dialect, introspection, partitioning, transactions, capability
gates and testing. For the framework itself (models, fields, queries, relations,
migrations), see the [core library documentation](https://github.com/rhosocial/python-activerecord/tree/main/docs/en_US).
