# 支持的版本

## SQL Server 版本支持

| SQL Server 版本 | 支持状态 | 说明 |
|--------------------|----------------|-------|
| SQL Server 2016 | ✅ 支持 | 引入原生 JSON 支持 |
| SQL Server 2017 | ✅ 支持 | |
| SQL Server 2019 | ✅ 支持 | 版本元组 (15, 0, 0) |
| SQL Server 2022 | ✅ 推荐 | 当前主流版本 (16, 0, 0) |
| SQL Server 2025 | ✅ 支持 | 最新版本 (17, 0, 0) |
| Azure SQL Database | ✅ 支持 | 与 2022 功能集兼容 |

> **重要**：此后端专为 Microsoft SQL Server 设计。方言行为与 T-SQL 版本特定功能紧密耦合。方言在连接时通过 `SERVERPROPERTY('ProductVersion')` 根据实际服务器版本进行调整。

## 版本特定功能检测

方言根据检测到的服务器版本调整其行为：

| 功能 | 最低版本 |
|---------|-----------------|
| CTE（递归） | 2008 |
| MERGE 语句 | 2008 |
| 窗口函数（增强） | 2012 |
| `OFFSET ... FETCH` 分页 | 2012 |
| 列存储索引 | 2012+ |
| 原生 JSON 函数 | 2016 |
| `APPROX_COUNT_DISTINCT` | 2019 |
| `JSON_OBJECT` / `JSON_ARRAY` | 2022 |
| 位运算函数（新） | 2022 |

## 依赖要求

| 依赖 | 版本 | 说明 |
|-----------|---------|-------|
| rhosocial-activerecord | >=1.0.0.dev0,<2.0.0 | 核心库 |
| pyodbc | >=5.3.0 | SQL Server 驱动（必需） |
| aioodbc | >=0.5.0 | 异步驱动（可选，用于异步支持） |
| 用于 SQL Server 的 ODBC 驱动 | 17 或 18 | 系统级 ODBC 驱动（必需） |

⚠️ **注意**：除了 `pyodbc` Python 包之外，访问 SQL Server 还需要系统级的 ODBC 驱动。
