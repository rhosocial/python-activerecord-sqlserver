# dml tests

SQL Server DML integration: real-database CRUD, column type mapping and execute_many batch operations.

## Key files

- `test_column_mapping_backend.py` — column type mapping
- `test_column_mapping_backend_async.py` — async column type mapping
- `test_crud_backend.py` — CRUD integration
- `test_crud_backend_async.py` — async CRUD integration
- `test_execute_many.py` — batch execution
