Adopted core's four-family introspection split — structure, operational
statistics, data profiling and DDL extraction, each with an async twin — and
removed the duplicate `supports_partition_info()` probe without an alias. The
partition read gate is now separate from the partition DDL gate:
`supports_partition_metadata_introspection()` answers `True` from SQL Server
2008 on every edition, while `supports_table_partitioning()` keeps the
Enterprise feature-set gate, so a Standard or Express server can report a
table's partitioning without being offered partition DDL, and a `False` from
the DDL probe no longer reads as "cannot read".
